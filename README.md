# Credit Card Fraud Detection — MLOps Pipeline

## 🔎 Концепция

Проект представляет собой end‑to‑end MLOps‑конвейер для обнаружения мошеннических операций по кредитным/банковским картам.
Цель: от загрузки «сырых» транзакционных данных до обучения, версионирования, развертывания и эксплуатации модели машинного обучения в условиях production‑окружения.

Основные задачи:

* автоматическая обработка и предобработка данных;
* обучение и оценка моделей машинного обучения;
* упаковка модели и её развертывание (inference / API / приложение);
* мониторинг, хранение экспериментов, повторное обучение и поддержка жизненного цикла модели.

## 🚀 Быстрый старт

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/outLimite/credit-card-craud-detection-mlops.git
   cd credit-card-craud-detection-mlops
   ```

2. (Рекомендовано) Создайте виртуальное окружение и активируйте его:

   ```bash
   python -m venv venv
   source venv/bin/activate     # Linux / macOS  
   # или venv\Scripts\activate  # Windows  
   ```

3. Установите зависимости (если есть файл `requirements.txt`):

   ```bash
   pip install -r requirements.txt
   ```

4. Подготовьте (или загрузите) набор данных транзакций, который будете использовать для обучения/тестирования.

5. Запускайте pipeline обучения / предобработки / инференса согласно вашим скриптам.

## 🐳 Развёртывание через Docker Compose

1. Убедитесь, что у вас установлен Docker и Docker Compose:

   ```bash
   docker --version
   docker-compose --version
   ```

2. Создайте или проверьте `docker-compose.yml` с сервисами

3. Запустите контейнеры:

   ```bash
   docker-compose up --build
   ```

## 🧠 Подход / Технологии

* Язык: Python
* Библиотеки для обработки данных: pandas, numpy и др.
* ML‑инструменты: scikit-learn, возможно библиотеки для работы с дисбалансом классов (oversampling / undersampling / SMOTE и т.д.). Такой подход широко используется в проектах обнаружения мошенничества. 
* MLOps‑инструменты и процессы: versioning данных / моделей / экспериментов; контейнеризация;

## 🎯 Почему это важно

Обнаружение мошенничества по банковским картам — критически важная задача: данные, с которыми мы работаем, чувствительны, а ошибки могут дорого стоить. MLOps‑подход позволяет сделать решение надёжным, воспроизводимым и масштабируемым.
